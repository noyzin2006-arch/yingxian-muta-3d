## B. 人工视觉检查清单（浏览器真实渲染后逐项对照）

### B1 轮廓与体量（远景 / 剪影）
- [ ] 剪影可数出 **6 重屋檐**（底层重檐 + 其上 4 层单檐 + 攒尖顶）。
- [ ] 塔身为**八角形**平面，8 个转角清晰可辨，不是圆不是方。
- [ ] 逐层**向内收分**，形成向上折收的轮廓折线；一层→五层明显收窄但比例不失衡。
- [ ] 底层**最宽**（副阶周匝出裙檐），裙檐宽大。
- [ ] 顶部八角攒尖 + **铁刹**（细长金属杆 + 宝珠），刹杆不粗壮、不缺失。
- [ ] **塔基**为两层：下层方形大台基 + 上层八角台基，塔身坐于其上。

### B2 结构可辨性
- [ ] 每层檐下**斗栱**清晰成簇（不是平滑檐口），层数越多栱越密。
- [ ] 二层以上可见**平座栏杆**（望柱 + 栏板），形成水平线。
- [ ] 一层可见**副阶柱廊**（一圈独立柱列），与塔身柱列可区分。
- [ ] 斗栱形制差异可见：底部层出跳多、下部昂明显；上部层出跳递减。
- [ ] **柱脚内收（侧脚）**可感：柱身略向内倾。

### B3 屋面
- [ ] 屋面**平直、角翘平缓**（不出现明清那种夸张起翘）。
- [ ] 八条戗脊交汇于攒尖顶，戗脊上有脊兽/瓦件节奏。
- [ ] 檐口有**风铃**（小挂件）点缀（可选但加分）。
- [ ] 瓦面为**筒板瓦**质感，不是光滑塑料面。

### B4 材质
- [ ] 木构呈**深棕偏灰**的老木质感，有**纹理与色差**（不是纯色块）。
- [ ] 有**彩画**但克制（宋代五彩），只在额枋/斗栱局部，不喧宾夺主。
- [ ] 砖石台基有砖缝/石材肌理，与木构区分明显。
- [ ] 琉璃脊件有釉面高光。
- [ ] 通场**没有**明显的 Z-fighting、重叠闪烁、硬边白缝。

### B5 光照（三态各查一遍）
- [ ] **白天**：方向光明确，投影方向与太阳一致，塔身受光/背光面有差别。
- [ ] **黄昏**：暖色低角度，长投影，氛围成立。
- [ ] **夜晚**：有灯笼/佛光等暖点光源，整体暗部不死黑，**不刺眼**（无过曝白斑）。
- [ ] 天空/环境与地面有联系（不要"模型浮在虚空"）。
- [ ] 阴影不出现明显锯齿/条纹（阴影贴图分辨率足够或已软化）。

### B6 交互
- [ ] 拖拽可绕塔旋转，阻尼自然；缩放有近/远限制，不会穿进模型或翻到地下。
- [ ] 预设机位切换有**平滑过渡**（不是瞬移）。
- [ ] 点击热点 → 出现构件解说（斗栱 / 平座 / 副阶 / 塔刹 / 塔基 / 造像…），信息正确。
- [ ] 剖切 / 分解视图能看到**内部**：内槽柱网、暗层、佛坛与造像。
- [ ] 昼夜切换即时生效，无残留状态。

### B7 信息层与排版
- [ ] 全中文，术语准确（斗栱、甍、举折、平座、副阶周匝、暗层、叉柱造…）。
- [ ] 说明文字分层清晰：标题 / 要点 / 详情，有留白。
- [ ] 正文在 1280 宽下可读，不溢出、不压字。
- [ ] 字体在中文下渲染正常（无缺字/方框）。

## C. 运行期检查

| 项 | 方法 | 通过标准 |
|---|---|---|
| 真实启动 | 本地起服务（`npm run dev` 或 `npm run preview`），浏览器打开 | 页面完整渲染，无致命错误 |
| Console | 浏览器 Console 查询 | **0 个 error**（warning 可接受并记录） |
| Network | 失败/4xx/5xx 请求 | **0 个失败请求**；无外部 CDN 依赖（或全部本地可用） |
| 帧率 | 页面内 `requestAnimationFrame` 计数 3 s 求平均，或 Chrome DevTools Performance | 本机（M5 Max）桌面视口 ≥ 55 fps；降级档 ≥ 30 fps |
| 像素比 | 检查 `renderer.getPixelRatio()` | ≤ 2（本机上限），低端档 ≤ 1.5 |
| 三角形/绘制调用 | `renderer.info.render` | 绘制调用在可控范围（建议 < 300） |
| 内存 | `renderer.info.memory` | 几何体/纹理数不持续增长（切换热点/剖切后回落） |
| 响应式 | 视口 1440×900 / 1024×768 / 768×1024 / 390×844 | 无横向滚动条；UI 不遮挡模型；触控可操作 |
| 键盘 | Tab 聚焦、Enter 激活 | 核心控件可键盘操作，焦点可见 |
| 降级 | 关闭后期 / 降低阴影分辨率 / 触发低性能分支 | 画面仍可用，不崩溃 |
| 真实运行 | 静态预渲染图 | **禁止**用截图或视频替代实时渲染 |

## D. 与真实照片的对照（终极还原度）

- [ ] 找 3 张不同角度的应县木塔实拍（正面、45°、仰视）作为参照。
