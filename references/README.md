# 参照照片（验收时用于对照还原度）

## 用途

在真实浏览器里渲染出模型后，把这些**实物照片**与渲染结果并排对照，检查轮廓、比例、屋檐节奏、
斗栱形制、材质色调是否「像真的」——这是「极尽还原」唯一有意义的检验方式。

**这些照片只用于人工比对，不会被打包进网页产物。**

## 对照要点（对应 `../acceptance-checklist.md` D 节）

1. **高宽比**：照片里塔是**敦厚**的，约为底层直径的 2.2 倍，不是瘦高。
2. **檐口节奏**：每层出挑递减、角翘平缓；底层裙檐最宽大。
3. **收分折线**：外檐柱层层内收形成折线，内槽柱一至四层不收。
4. **塔基比例**：台基约占全高 1/15，不笨重也不悬空。
5. **攒尖与铁刹**：刹杆约占全高 1/7 强，细长不粗壮。
6. **色调**：老木深褐偏灰，彩画克制，砖石与木构质感分明。

## 判读注意

- 照片为透视视角，量比例时以**塔基与塔刹顶**为基准做粗略换算，不做精确量测。
- 部分照片为 1963 年或雨雾天拍摄，色调偏灰，**不要把拍摄条件当成木料本色**。
- 木塔因长期倾斜（塔顶水平位移约北偏东 10.8°）已有形变；模型应呈现**原始设计规整状态**，
  不复制倾斜。
